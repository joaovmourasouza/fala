# Flathub submission notes: io.github.joaovmourasouza.Fala

## What the app does

Fala is a voice dictation app (similar to Wispr Flow) for GNOME/Wayland. The user presses a global
shortcut, speaks, and the text is transcribed locally with Whisper (faster-whisper), polished by
Claude Code and pasted into the focused window.

## Permissions

| Permission | Why |
|---|---|
| `--socket=wayland`, `--socket=fallback-x11`, `--share=ipc`, `--device=dri` | Qt GUI (dashboard window and recording overlay) |
| `--socket=pulseaudio` | Microphone capture |
| `--share=network` | Downloads the Whisper model from Hugging Face on first use; optional Groq transcription API |
| `--talk-name=org.freedesktop.Notifications` | Error/status notifications |
| `--talk-name=org.freedesktop.Flatpak` | See below |

Everything else goes through portals: GlobalShortcuts (dictation shortcut, tap or hold), RemoteDesktop
(keyboard only, to press Ctrl+V into the focused window; the session is opened just for the paste
and closed right after), and Background (autostart).

## Exception request: `--talk-name=org.freedesktop.Flatpak`

Text polishing runs `claude -p` (Claude Code, Anthropic's CLI) **on the host**, via
`flatpak-spawn --host`. This is the app's core design choice, not a convenience:

- The user's Claude Code installation holds their own login (OAuth/subscription). Running it on
  the host lets Fala use that login, so the user does not need to create, paste or store an API key
  inside the sandbox. This is the main feature advertised in the description ("No API key needed").
- Claude Code is a proprietary CLI installed per user (usually in `~/.local/bin`), updated by
  itself and not redistributable, so it cannot be bundled in the Flatpak.
- Its credentials live in the host's config/keyring; exposing them to the sandbox through
  filesystem permissions would be a broader and less safe hole than invoking the CLI.

Scope of host execution (see `src/fala/host.py`):

- Only two fixed commands are run: `command -v claude` (availability check at startup) and
  `claude -p` with a fixed argument list: `--tools ""` (no tools: Claude cannot run commands or read
  files), `--strict-mcp-config`, `--setting-sources ""`, `--no-session-persistence`, a fixed system
  prompt and the transcription on stdin.
- Commands run from `/tmp` on the host, so no project `CLAUDE.md` is picked up.
- No user-controlled string is interpolated into a shell command; the transcription is passed only
  through stdin.
- If Claude Code is not installed, Fala keeps working and pastes the raw Whisper transcription.

## Binary wheels

`python3-deps.yaml` is generated by `flatpak-pip-generator` (`flatpak/requirements.txt`).
Platform wheels are used for numpy, ctranslate2, onnxruntime, av, tokenizers, pyyaml, cffi, hf-xet
and protobuf. These are large native ML libraries (ctranslate2 and onnxruntime need CUDA/MKL
toolchains to build from source). Happy to move any of them to source builds if reviewers prefer.
PyQt6 comes from `com.riverbankcomputing.PyQt.BaseApp`.
