# Fala

Clone brasileiro do [Wispr Flow](https://wisprflow.ai): ditado por voz em qualquer app.
Segure uma tecla de atalho, fale, solte — o texto transcrito (e limpo por um LLM) é digitado no campo em foco.

## Objetivos (MVP)

- [ ] Atalho global push-to-talk
- [ ] Captura de áudio do microfone
- [ ] Transcrição (Whisper local ou API)
- [ ] Pós-processamento com LLM (pontuação, remoção de "é...", "tipo", formatação)
- [ ] Inserção do texto no app ativo (clipboard + paste / simulação de teclado)
- [ ] Indicador visual flutuante de gravação
